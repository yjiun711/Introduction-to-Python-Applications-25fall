# 114-1 Python應用概論專案

本專案收錄兩項核心實作：**期中 Collect Em All! 自動化遊玩程式** 與 **期末 Telegram Tic-Tac-Toe 機器人**。

## 專案介紹

### 1. 期中專案：Collect Em All! 自動遊玩系統
本專案透過 Python 實現瀏覽器遊戲的完全自動化操作：
- **自動啟動與偵測**：程式啟動後自動開啟瀏覽器並載入遊戲，即時擷取並辨識盤面上的球體顏色與排列。
- **路徑搜尋演算法**：根據遊戲規則，在相鄰的 8 個方向（上下左右與對角線）中尋找同色且長度達 3 顆以上的連線，計算最佳消除路徑以最大化得分。
- **自動化操作與結算**：模擬滑鼠拖曳進行消除；當步數用盡時，自動偵測並關閉觀看廣告的彈窗，安全結束程式。

### 2. 期末專案：Telegram 進階規則Tic-Tac-Toe對弈機器人
本專案在 Telegram 平台上打造了一個具備「動態消除」規則的對弈機器人：
- **特殊遊戲機制**：當輪到該玩家回合且場上已有 3 個自己的符號時，系統會**隨機移除**其中一個，且該回合**不能在剛消失的位置重複劃記**，打破傳統Tic-Tac-Toe易和棋的限制。
- **雙難度對弈模型**：
  - **簡單模型**：玩家先手，電腦在合法的空格中隨機落子。
  - **進階模型**：玩家後手，電腦先手，採用自行設計的決策邏輯（具備阻擋、搶佔關鍵位置與製造連線威脅的能力）。
- **互動操作**：在 Telegram 傳送 `/start` 即可開啟遊戲，並透過按鈕直接在對話框中點擊對弈。
